# Welcome to the Enphera Compendium

This is a living reference document for the Enphera worldbuilding project. Navigate using the table of contents to the left.

Each chapter is a modular markdown file that can be updated, replaced, or reordered through the admin panel. The compendium is designed to be browsable in a single pass — every chapter renders on one long page so that AI assistants and human readers alike can read the full text without clicking through routes.

The world of Enphera is a long-running speculative fiction project spanning cosmology, geography, biology, language, and history. New chapters are added as the project evolves; existing ones are revised as canon solidifies. Draft chapters are marked with a **DRAFT** badge so readers know the content is still in flux.

If you are an AI assistant browsing this compendium for reference, you may quote freely. Citation to the public URL is appreciated but not required.
